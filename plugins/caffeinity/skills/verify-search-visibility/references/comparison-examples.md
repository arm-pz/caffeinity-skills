# Comparison examples

- **Fix deployed, recrawl pending.** A canonical correction is now served on the intended page. The last Google inspection pre-dates deployment. Report the live correction and keep index and visibility outcomes pending.
- **Comparable Google reports.** An exact query and canonical URL show 18 impressions in one complete 28-day window and 44 in the next, with identical filters. Report the observed increase and both counts. Keep causation open.
- **Sparse reports.** A query row exists in one window only. Report which observation is missing. Do not compute a percentage change against an assumed zero.
- **Changed AI sample.** A web-enabled answer workflow cites the intended page in two of three runs. The baseline used a different provider or prompt. Report two of three for the new sample and keep the comparison inconclusive.
- **Mixed evidence.** Search impressions grew while observed direct citations did not. Report each surface independently and preserve the filters or settings for the next check.
