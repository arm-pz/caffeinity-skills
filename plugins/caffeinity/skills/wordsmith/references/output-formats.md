# Output formats

Use the format appropriate to the command.

## Rewrite

```text
[revised text]

Notes:
- [brief summary of meaningful changes]
```

## Edit

```text
[edited text]

Changes:
- [important changes only]
```

## Critique

```text
Overall assessment:
[short assessment]

What works:
- ...

Main weaknesses:
- ...

Highest-value improvements:
1. ...
2. ...
3. ...

Example revision:
...
```

## Audit

```text
Scorecard:
- Purpose clarity: /5
- Audience fit: /5
- Structure: /5
- Opening strength: /5
- Specificity: /5
- Evidence: /5
- Tone: /5
- Voice consistency: /5
- Readability: /5
- Concision: /5
- Accessibility: /5
- Factual risk: /5
- Call to action: /5

Findings:

Severity: P0/P1/P2/P3
Location:
Problem:
Why it matters:
Recommended action:
```

## Draft

```text
[complete draft]

Assumptions:
- [only if important]

Notes:
- [brief note about significant choices]
```

## Final

```text
Final copy:
[publication-ready copy]

Needs confirmation:
- [unresolved item, if any]
```

## Comparison

```text
Recommendation:
[Version A, Version B, or context-dependent]

Version A strengths:
- ...

Version A weaknesses:
- ...

Version B strengths:
- ...

Version B weaknesses:
- ...

Reasoning:
...
```

## Natural-language requests

For ordinary requests, do not force the user to see command names. Simply perform the appropriate operation and use the shortest useful explanation.
