# Writing outcomes

An outcome is something a learner does that someone else can see. Write it as
**verb + object + condition**: "Given a CSV of sales, *build* a pivot table that answers a stated
question."

## Verbs by level

| Level | Use | Example |
| --- | --- | --- |
| Recall | list, name, define, identify, label | identify the parts of an HTTP request |
| Explain | explain, describe, compare, summarise, classify | compare two caching strategies for a given site |
| Apply | use, build, run, solve, implement, configure, calculate | configure a deploy pipeline for a static site |
| Analyse | diagnose, debug, distinguish, test, trace | diagnose why a page fails a performance budget |
| Judge | evaluate, critique, justify, choose, prioritise | justify a launch or hold decision from a checklist |
| Create | design, write, produce, plan, compose | design a module for a beginner audience |

## Avoid

`understand`, `know`, `learn`, `appreciate`, `be aware of`, `be familiar with`, `gain insight`.
They describe what happens in the learner's head, which no assessment can see. The checker warns
when an outcome starts with one.

## Course outcomes versus module outcomes

Course outcomes (3 to 8) are what the certificate claims. Module outcomes are smaller steps
toward them; the JSON links each module to the course outcomes it serves. Most of a course's
outcomes should sit at Apply or above; a course of only Recall outcomes is a reading list.
