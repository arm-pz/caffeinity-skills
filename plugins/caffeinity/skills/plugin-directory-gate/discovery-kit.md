## 5. Release notes (v1.0.0)

First release. Checks a Claude Code plugin folder against the Claude plugin directory's submission
rules for organizations that aren't Verified and returns GO or HOLD with findings by file and line.
Includes `scripts/screen.py` (read-only, no network), `scripts/test_screen.py` (16 cases),
`references/rules.md` (the portal's rules and what passed or failed in practice) and trigger cases
in `tests.md`. Calibrated against two real portal reports on 2026-11-22.
Install: `npx skills add arm-pz/plugin-directory-gate`.
