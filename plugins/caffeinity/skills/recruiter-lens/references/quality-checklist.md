# Quality Checklist

## Pre-Submission Resume Checklist

### Content Quality
- [ ] Contact information is complete and professional (email, phone, LinkedIn)
- [ ] Summary/objective is tailored to specific role (not generic)
- [ ] All bullet points include impact/outcomes, not just responsibilities
- [ ] Quantifiable metrics included wherever possible (%, $, #, time)
- [ ] Skills section matches job description requirements
- [ ] Employment timeline is clear with no unexplained gaps >6 months
- [ ] Education and certifications are listed if required by role

### Formatting & Presentation
- [ ] Single-column layout (no tables or text boxes)
- [ ] Standard fonts only (Arial, Calibri, Times New Roman, Helvetica, Georgia, Verdana)
- [ ] Consistent date formatting throughout (recommend MMM YYYY)
- [ ] Section headers use standard labels (Experience, Education, Skills)
- [ ] No special characters that break ATS (arrows, checkmarks, emojis)
- [ ] Adequate white space and readable font size (10-12pt body, 14-16pt headers)
- [ ] Contact info in main body (NOT in header/footer)
- [ ] Length appropriate for experience level (1-2 pages max for <10 years)

### ATS Compatibility
- [ ] Saved as PDF (unless .docx specifically requested)
- [ ] File name is professional (FirstName_LastName_Resume.pdf)
- [ ] No graphics/images with embedded text
- [ ] No password protection
- [ ] File size <2MB
- [ ] Copy-paste test: Content appears in logical order when pasted to plain text

### Accuracy & Honesty
- [ ] All claims are truthful and defensible in interview
- [ ] No exaggerated titles or fabricated achievements
- [ ] Dates are accurate (no extending employment to hide gaps)
- [ ] Skills listed are ones you can discuss competently
- [ ] Company names and roles are correctly stated

### Tailoring
- [ ] Resume includes keywords from specific job description
- [ ] Summary mentions company/role explicitly
- [ ] Most relevant experience is emphasized/prominent
- [ ] Irrelevant details minimized or removed
- [ ] Cover letter (if submitted) is custom-written for this role

### Final Review
- [ ] Spell-checked (no typos or grammatical errors)
- [ ] Proofread by second person (friend, mentor, colleague)
- [ ] Viewed at 100% zoom to check spacing/layout
- [ ] Printed version reviewed (catches issues screen misses)
- [ ] Links tested (LinkedIn, portfolio, GitHub all work)
- [ ] Email address tested (send yourself a test email)

## LinkedIn Profile Checklist

### Completeness
- [ ] Professional headshot uploaded (well-lit, business casual)
- [ ] Background banner image present (branded or industry-relevant)
- [ ] Headline goes beyond current title (includes value proposition)
- [ ] About section is 3-5 paragraphs telling your story
- [ ] All recent experience listed (last 10 years minimum)
- [ ] Education completed with degree/dates
- [ ] 15-25 skills listed (mix of technical and soft skills)
- [ ] Custom LinkedIn URL created (linkedin.com/in/firstname-lastname)

### Optimization
- [ ] Keywords from target roles appear in headline, about, and experience
- [ ] Experience descriptions include outcomes, not just duties
- [ ] Featured section showcases best work (portfolio, articles, projects)
- [ ] Recommendations received (3+ from managers/colleagues)
- [ ] Recent activity visible (posts, comments, shares within last month)
- [ ] Industry and location are current and accurate
- [ ] Contact info visible (email or "Open to Work" settings configured)

### Discoverability
- [ ] Skills include technologies mentioned in target job descriptions
- [ ] Headline contains searchable terms (not just internal job title)
- [ ] About section includes industry keywords naturally
- [ ] Groups joined relevant to target industry/role
- [ ] Connections growing strategically (target company employees, recruiters)

## Cover Letter Checklist

### Structure
- [ ] Opening paragraph states specific role and why interested
- [ ] Body paragraphs connect experience to job requirements
- [ ] Specific examples provided (not just general claims)
- [ ] Closing paragraph expresses enthusiasm and call to action
- [ ] Length is 3-5 paragraphs (250-400 words total)

### Content
- [ ] Company name mentioned explicitly
- [ ] Shows research about company (mission, values, recent news)
- [ ] Explains why THIS role, not just any role
- [ ] Addresses potential concerns proactively (gaps, pivots, relocation)
- [ ] Tone matches company culture (formal vs. casual)
- [ ] No repetition of resume bullet points verbatim

### Quality
- [ ] Written in authentic voice (doesn't sound AI-generated)
- [ ] Free of typos and grammatical errors
- [ ] Formatted cleanly with proper spacing
- [ ] Saved as PDF with professional filename
- [ ] Addressed to specific person if possible (not "To Whom It May Concern")

## Interview Preparation Checklist

### Research
- [ ] Company website reviewed (products, mission, values)
- [ ] Recent news/articles about company read
- [ ] Interviewers' LinkedIn profiles reviewed (background, commonalities)
- [ ] Job description re-read and requirements noted
- [ ] Company's competitors/market position understood

### Story Preparation
- [ ] 5 versatile STAR stories prepared covering:
  - [ ] Conflict/disagreement resolution
  - [ ] Failure or mistake and lessons learned
  - [ ] Success/achievement with measurable impact
  - [ ] Leadership or initiative taken
  - [ ] Learning new skill/technology quickly
- [ ] Each story practiced aloud (2-3 minutes each)
- [ ] Stories include specific details (names, numbers, timelines)

### Technical Prep
- [ ] Key technologies from JD reviewed
- [ ] Common interview questions for role researched
- [ ] Portfolio/projects ready to demonstrate
- [ ] Coding challenges practiced (if applicable)
- [ ] Questions prepared to ask interviewer (5+ thoughtful questions)

### Logistics
- [ ] Interview time confirmed (timezone checked)
- [ ] Location/link tested (video call software installed)
- [ ] Professional attire prepared
- [ ] Resume copies printed (for in-person)
- [ ] Notebook and pen ready
- [ ] Backup plan for tech issues (phone number available)

## Application Tracking Checklist

For each application, track:
- [ ] Company name
- [ ] Role title
- [ ] Date applied
- [ ] Application method (company site, LinkedIn, referral, etc.)
- [ ] Job posting URL (saved for reference)
- [ ] Resume version used (tailored filename)
- [ ] Cover letter sent (Y/N)
- [ ] Referral source (if applicable)
- [ ] Follow-up date scheduled
- [ ] Status (submitted, screening, interview, offer, rejected)
- [ ] Notes (interviewer names, feedback, next steps)

**Recommended tools:** Spreadsheet, Notion database, Airtable, or dedicated app like Huntr/Teal

## Red Flag Self-Audit

Before submitting, ask:

### Employment History
- [ ] Are there any unexplained gaps >6 months? If yes, addressed proactively?
- [ ] Is there a job-hopping pattern (3+ roles in <2 years)? If yes, context provided?
- [ ] Do dates overlap suspiciously? If yes, explained (freelance + full-time)?

### Presentation
- [ ] Would I be embarrassed if my current boss saw this resume? If yes, revise
- [ ] Does the email address look professional? If no, create Gmail account
- [ ] Are there any typos in the first paragraph? If yes, proofread entire document

### Fit
- [ ] Am I applying because genuinely interested, or just desperate? If latter, reconsider
- [ ] Can I defend every claim in an interview confidently? If no, remove or prepare
- [ ] Does this resume clearly show why I'm fit for THIS role? If no, tailor more

### Authenticity
- [ ] Have I exaggerated titles or responsibilities? If yes, correct to accurate
- [ ] Are all metrics real (not invented)? If no, use scope indicators instead
- [ ] Would I feel comfortable if they called my references right now? If no, fix first

## Post-Rejection Review Checklist

When rejected, analyze:

- [ ] At what stage did rejection occur?
  - ATS filter → Improve keywords/formatting
  - After recruiter screen → Strengthen resume content
  - After hiring manager review → Better tailoring needed
  - After interview → Improve interview skills or address concerns proactively

- [ ] Can I request feedback? (Some companies will share reasons)

- [ ] What pattern do I see across multiple rejections?
  - Same issue repeatedly → Fix systemic problem
  - Random rejections → Normal; increase volume or improve targeting

- [ ] Should I reapply later? (Some companies allow reapplication after 6-12 months)

- [ ] What did I learn from this application process?

- [ ] What will I do differently next time?

## Continuous Improvement Checklist

Monthly review:
- [ ] Update resume with new achievements/skills
- [ ] Refresh LinkedIn with recent activity
- [ ] Expand professional network (10+ new relevant connections)
- [ ] Learn one new skill or deepen existing skill
- [ ] Review application conversion rates (applications → screens → interviews → offers)
- [ ] Identify bottlenecks and address them
- [ ] Seek feedback from mentors/peers on materials
- [ ] Research market trends in target industry/role
- [ ] Update portfolio/projects with recent work
- [ ] Practice interview skills (mock interviews, recording self)
