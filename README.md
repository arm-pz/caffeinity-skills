# caffeinity-skills

A Claude Code plugin marketplace for Abdul Rahman P Z's skills. Not sure which one you need? Install `caffeinity-routing` first: it maps a goal to the skills, in order. The skills: caffeinity-routing, wordsmith, recruiter-lens, applicant-kit, topic-primer, application-pilot, do-better, keyword-guard, seo-crawl, web-preflight, findable, crash-test, pre-ship-performance-audit, pre-ship-security-red-team, release-gate, publish-release-gate, upstream-check, tune-skill, draft-skill, prompts-to-skill, prompts-to-skill-release, publish-pipeline, cold-email-ops, and cold-email-list-gate.

## Install

```
/plugin marketplace add arm-pz/caffeinity-skills
/plugin install wordsmith@caffeinity-skills
```

Replace `wordsmith` with any of: `caffeinity-routing`, `recruiter-lens`, `applicant-kit`, `topic-primer`, `application-pilot`, `do-better`, `keyword-guard`, `seo-crawl`, `web-preflight`, `findable`, `crash-test`, `pre-ship-performance-audit`, `pre-ship-security-red-team`, `release-gate`, `publish-release-gate`, `upstream-check`, `tune-skill`, `draft-skill`, `prompts-to-skill`, `prompts-to-skill-release`, `publish-pipeline`, `cold-email-ops`, `cold-email-list-gate`.

Each plugin lives in its own repository (see `.claude-plugin/marketplace.json` for sources).
