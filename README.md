# caffeinity-skills

A Claude Code plugin marketplace for Abdul Rahman P Z's skills: wordsmith, recruiter-lens, deep-tutor, do-better, keyword-guard, and web-preflight.

## Install

```
/plugin marketplace add arm-pz/caffeinity-skills
/plugin install wordsmith@caffeinity-skills
```

Replace `wordsmith` with any of: `recruiter-lens`, `deep-tutor`, `do-better`, `keyword-guard`, `web-preflight`.

Each plugin lives in its own repository (see `.claude-plugin/marketplace.json` for sources).
