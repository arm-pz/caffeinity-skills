# caffeinity-skills

A Claude Code plugin marketplace for Abdul Rahman P Z's skills: wordsmith, recruiter-lens, applicant-kit, topic-primer, application-pilot, do-better, keyword-guard, web-preflight, findable, and crash-test.

## Install

```
/plugin marketplace add arm-pz/caffeinity-skills
/plugin install wordsmith@caffeinity-skills
```

Replace `wordsmith` with any of: `recruiter-lens`, `applicant-kit`, `topic-primer`, `application-pilot`, `do-better`, `keyword-guard`, `web-preflight`, `findable`, `crash-test`.

Each plugin lives in its own repository (see `.claude-plugin/marketplace.json` for sources).
