# caffeinity-skills

A Claude Code plugin marketplace for Abdul Rahman P Z's skills: wordsmith, recruiter-lens, applicant-kit, topic-primer, application-pilot, do-better, keyword-guard, seo-crawl, web-preflight, findable, crash-test, pre-ship-performance-audit, pre-ship-security-red-team, release-gate, publish-release-gate, upstream-check, tune-skill, draft-skill, prompts-to-skill, prompts-to-skill-release, and publish-pipeline.

## Install

```
/plugin marketplace add arm-pz/caffeinity-skills
/plugin install wordsmith@caffeinity-skills
```

Replace `wordsmith` with any of: `recruiter-lens`, `applicant-kit`, `topic-primer`, `application-pilot`, `do-better`, `keyword-guard`, `seo-crawl`, `web-preflight`, `findable`, `crash-test`, `pre-ship-performance-audit`, `pre-ship-security-red-team`, `release-gate`, `publish-release-gate`, `upstream-check`, `tune-skill`, `draft-skill`, `prompts-to-skill`, `prompts-to-skill-release`, `publish-pipeline`.

Each plugin lives in its own repository (see `.claude-plugin/marketplace.json` for sources).
